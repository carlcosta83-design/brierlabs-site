We changed our model and restarted the record

Nous avons changé de modèle et remis le relevé à zéro

Until now, almost every call on this site was produced after the market had opened. The daily run was scheduled for early morning, but GitHub, the service that runs it, started every scheduled run between four and ten hours late. The calls were still dated that same day and measured from the opening price, so the model was reading headlines that already described the session it was meant to predict. Of the 714 calls recorded between 30 August and 12 November 2026, 678 (95%) were produced after the open.

Jusqu’ici, presque tous les appels de ce site ont été produits après l’ouverture du marché. Le run quotidien était programmé tôt le matin, mais GitHub, le service qui le lance, a démarré chaque run programmé avec quatre à dix heures de retard. Les appels restaient pourtant datés du jour même et mesurés depuis le cours d’ouverture : le modèle lisait donc des titres qui décrivaient déjà la séance qu’il devait prédire. Sur les 714 appels enregistrés entre le 30 août et le 12 novembre 2026, 678 (95 %) ont été produits après l’ouverture.

That flatters the results, including the most encouraging ones this site had shown. Those figures should be set aside. We found the problem by checking the time each run actually started, not the time it was scheduled for.

Cela flatte les résultats, y compris les plus encourageants que ce site avait affichés. Ces chiffres sont à écarter. Le problème a été trouvé en vérifiant l’heure à laquelle chaque run a réellement démarré, et non celle à laquelle il était prévu.

What we did

Ce que nous avons fait

The old calls are not deleted. They stay in the database and in the downloadable file, marked as an archive, but no figure on this site counts them any more. The record starts again from zero on 13 November 2026, with the first call produced before the opening bell. Each run is now launched on request around 6 a.m., and the system refuses to date a call for a session that has already opened: a run that comes in late either stops or is dated for the next session.

Les anciens appels ne sont pas effacés. Ils restent dans la base et dans le fichier téléchargeable, marqués comme archive, mais plus aucun chiffre du site n’en tient compte. Le relevé repart de zéro le 13 novembre 2026, avec le premier appel produit avant l’ouverture. Chaque run est désormais lancé sur commande vers 6 h, et le système refuse de dater un appel d’une séance déjà ouverte : un run en retard s’arrête, ou est daté de la séance suivante.

A new model

Un nouveau modèle

We used the restart to change the model itself. It now gives four separate verdicts for each stock: one for the next session, one for the week, one for the month and one for the year. Each is scored against its own neutral band, which widens with time: ±0.50%, ±1.32%, ±2.74% and ±7.94%. A move of half a percent means something over a day and nothing over a year.

Nous avons profité de la remise à zéro pour changer le modèle lui-même. Il rend désormais quatre verdicts distincts pour chaque titre : un pour la prochaine séance, un pour la semaine, un pour le mois et un pour l’année. Chacun est noté contre sa propre zone neutre, qui s’élargit avec le temps : ±0,50 %, ±1,32 %, ±2,74 % et ±7,94 %. Un mouvement d’un demi-point veut dire quelque chose sur une journée, et rien sur une année.

Also new

Aussi nouveau

A newsletter every trading day before the open, with the day’s major news and the sectors each story could move. Each of its calls is tied to a listed sector fund, so that it can be checked against what the market actually did.

Une newsletter chaque jour de bourse avant l’ouverture, avec les nouvelles majeures du jour et les secteurs que chacune pourrait faire bouger. Chacune de ses prévisions est rattachée à un fonds sectoriel coté, pour pouvoir être vérifiée contre ce que le marché a réellement fait.
